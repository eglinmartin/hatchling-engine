# HATCHLING - A LÖVE2D ENGINE

<br> <img width="1920" height="320" alt="image" src="https://github.com/user-attachments/assets/147b723a-c924-4b71-987f-44ad6580fa5e" /> <br>

Hatchling is a custom game engine built on the [LÖVE2D Framework](https://love2d.org/).
The beauty of LÖVE2D is that it is very simple to use out-of-the-box. With love.load(), love.update() and love.draw(), you have the core of what you need to create your own games.
As freeing as this simplicity is, it is open to customizing in your own way.

After a few months of learning, I found methods of rendering, managing scenes and coordinating entities that worked really well for my style of game. **Hatchling** is these preferences, packed into a custom engine that can be installed easily by executable.

<br> <img width="1920" height="320" alt="image" src="https://github.com/user-attachments/assets/d85b7ab2-8d15-4d33-871b-9b8d3ccbca36" /> <br>

**Hatchling** requires [LÖVE2D](https://love2d.org/) to be installed on your machine. It currently only works on Windows - MacOS / Linux builds are planned in the future.  

To create a new game using Hatchling, download hatchling.exe from the latest release. The executable will request the base directory in which you store you repositories, and the name of the new game directory (and repository). It will create a new repository in this directory, copy in the template files, and bring down the latest version of Hatchling. What you do next is up to you.
